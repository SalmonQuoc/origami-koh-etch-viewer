## 2. Engine changes made in both versions

1. **Re-initialisation neighbour loop (bug).** In `makeReinit`, the loops over a node's six neighbours read the shared array `NB`, which `solve()` refills with the neighbours of the node being solved. After the first neighbour the loop therefore visited the neighbours of another node. The loops now read a copy. Found because the line-by-line Rust port, which has no shared array, disagreed with the JavaScript engine by several µm.
2. **No normalisation of the gradient before the rate look-up.** The table needs only the ratios of the sorted crystal components, so the three divisions by |∇φ| were dropped and the two ratio divisions became one reciprocal. Mathematically the same; it changes the last bits, identically in both versions.
